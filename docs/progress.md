## 아직 안 한 것

필요해지는 단계에서 넣는다.

- **사용:** 에나 외 코스트(코인·버리기)의 확정 전 선택, 《ターン1回》 등 횟수 제한, 모드 선택
- **장에 내기:** 피스, 레조나, 키, 어시스트 그로우
- **룰:** 룰 처리 8(붙는 카드 상한), 바이러스 표식, 그로우 조건, 리미트 어퍼
- **효과:** 「効果を受けない」, 「新たに得られない」. `EFFECT_GRANT`는 【起】·【自】만 확인(지속 효과 부여는 아직)
- **성능:** 값 계산 캐시(지금은 매번 전체 효과를 훑는다)
- **API:** 존 추가 메시지, 트리거 순서·모드 선택지에 설명(지금은 번호만 보인다)
- **프레임:** 카드 이미지, 네트워크 대전, 사람이 읽는 로그 다듬기, 대상·코스트를 장에서 바로 고르는 조작 다듬기
- **테스트 모드:** 코인 조작(코인 구현 때), 진행 중 페이즈 바꾸기, 리플레이 파일 저장·불러오기
